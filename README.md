## 📌 What is Photoshop?

Adobe Photoshop is the industry-leading application for **photo editing, retouching, digital painting, and graphic design**, used by photographers, designers, and artists worldwide.

## ✨ Key Features

| Feature | Description |
|---|---|
| Layer-based editing | Non-destructive editing with unlimited layers |
| AI tools (Generative Fill) | Adobe Sensei-powered smart editing |
| RAW photo processing | Full Camera Raw support |
| Cloud documents | Sync projects across devices |
| Plugin ecosystem | Huge library of third-party plugins |
